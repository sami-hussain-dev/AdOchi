Install in 1 minute

Android

  1. Tap Download APK and open the file.
  2. If asked, allow Install unknown apps for your browser.
  3. Open AdOchi and tap the big button. The VPN it asks for is the local filter on your phone.
  4. Long-press the icon for YouTube (no ads) and Facebook (no ads).

Chrome, Edge, Brave, Opera

  1. Download the ZIP and unzip it (right-click → Extract All).
  2. Open chrome://extensions (or edge://extensions).
  3. Turn on Developer mode.
  4. Load unpacked → pick the folder with manifest.json inside.

Firefox

  1. Download the Firefox ZIP.
  2. Open about:debugging#/runtime/this-firefox.
  3. Load Temporary Add-on → pick the ZIP.
